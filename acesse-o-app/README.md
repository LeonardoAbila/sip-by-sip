# Use o Sip by Sip

Acompanhe sua água do dia, consulte o calendário e veja seus dias consecutivos.

## Acesse o aplicativo

### [Abrir o Sip by Sip](https://leonardoabila.github.io/sip-by-sip/)

Funciona pelo navegador no celular ou computador. Não é necessário baixar o código, instalar programas ou ter uma conta no GitHub.

## Como começar

1. Abra o link acima e toque em **Cadastre-se**.
2. Escolha um usuário, uma senha de teste e confirme a senha.
3. Informe idade e peso, toque em **Descobrir minha meta** e depois em **Começar meu dia**.
4. Use **Garrafa** ou **Copo** para registrar a água. Os volumes aparecem nos botões; **Desfazer** remove o último registro.
5. Na mesma tela, consulte o calendário e os dias consecutivos. Em **Alterar ml**, ajuste o tamanho dos recipientes.

Em **Configurações**, você pode ajustar sua meta, o idioma, o modo escuro e os lembretes. Os lembretes funcionam com a página aberta e visível.

## Seus dados

Este é um protótipo com perfis locais: os dados ficam no navegador e no endereço em que você usa o app. A senha serve para entrar pelo aplicativo; ela não criptografa os dados. Use uma senha de teste.

O progresso não é sincronizado automaticamente entre dispositivos ou navegadores. Para guardar uma cópia, abra **Configurações → Backup do perfil → Exportar backup**. Você pode importar esse arquivo pelo painel de backup em outro perfil local; a importação substitui os dados do perfil escolhido após confirmação.
