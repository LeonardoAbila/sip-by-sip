# Agent instructions

## Project

Água do Dia is a water bottle counter built with React, JavaScript, and Vite. The app interface is in Portuguese. Keep code approachable: this repository also serves as a React learning project.

## Main files

- `src/App.jsx`: app components, dialogs, and user interactions.
- `src/state.js`: saved-state loading, validation, and migration.
- `src/theme.js`: saved and system theme preferences.
- `src/styles.css`: layout, styling, and theme palettes.
- `src/main.jsx`: React entry point.
- `README.md`: setup, behavior, and learning notes.

## Working conventions

- Make focused changes and preserve unrelated work.
- Keep user-facing text in Portuguese.
- Prefer simple React components and built-in browser features. Add dependencies only when needed.
- Preserve recorded water volume when bottle size changes.
- Reset daily progress on a new local calendar day while retaining settings.
- Keep browser storage loading resilient to missing or invalid data.
- Preserve keyboard access, dialog cancellation, and light/dark theme support when changing the interface.
- Update the README when setup or documented behavior changes.
- Edit source files; `dist/` is generated by the build.

## Commands and validation

- `npm install`: install dependencies.
- `npm run dev`: start the Vite development server.
- `npm run build`: validate the production build.
- `npm run preview`: serve the production build locally.

There is currently no automated test script. For app changes, run `npm run build` and manually verify the affected behavior when a browser is available. Relevant checks include adding bottles, saving/cancelling settings, refreshing saved progress, confirming/cancelling a reset, and switching themes. Report any verification that could not be performed.
